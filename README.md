# hingeipv6

Hinge config/ipv6 key checks for twelve-factor services.

**Site:** https://theworker02.github.io/hingeipv6/

## Install / run

```bash
git clone https://github.com/theworker02/hingeipv6.git
cd hingeipv6
node src/cli.js
node --test
```
